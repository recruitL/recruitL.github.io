<section class="briefing-item">
<h2>1. Teukolsky／Mathematica：PerturbationEquations 修正自旋 ±2 主 Teukolsky 算符中的质量符号错误</h2>
<p><span class="briefing-item__label">核心内容：</span>Black Hole Perturbation Toolkit 的 PerturbationEquations 更新把 MasterTeukolsky.wl 中误用的方位角量子数 m 改为黑洞质量 M，涉及自旋 +2 与 -2 的主方程系数。上游说明该修复后算符才与标准 s=±2 Teukolsky 方程一致；旧表达式在已知解上的残差可达 1 阶。</p>
<p><span class="briefing-item__label">为什么相关：</span>这是会直接改变频域 Kerr 微扰、QNM 与源项计算结果的符号级修复，优先级高于一般文档或样式更新。</p>
<p><span class="briefing-item__label">具体动作：</span>若本地 Mathematica 工作流使用该包，固定此提交或后续版本；以一个已知模态重新代入并记录 M、m 约定，再比较旧结果，勿把差异当成物理效应。</p>
<p class="briefing-sources"><span>来源：</span><a href="https://github.com/BlackHolePerturbationToolkit/PerturbationEquations/commit/e2e43a68600ecf1b1b760cd3d0f1213746c809ff">PerturbationEquations 官方修复提交</a></p>
</section>

<h2>2. Teukolsky／张量转换：PerturbationEquations 补齐频域 h± 规则并修复 BLS 坐标转换因子</h2>
<p><span class="briefing-item__label">核心内容：</span>同一官方修复还为 hp、hm 补上 t 导数到频域 -iω 的替换规则，修正 BLStotr 中两个分量缺失的 1/f 因子，并将 Master 输出中的裸 r 改为 r[]。更新同时更正 λ2 的角谐函数归一化表达式。</p>
<p><span class="briefing-item__label">为什么相关：</span>这些规则处在从时域张量、四分量基底到频域微扰方程的接口；遗漏后会留下未转换导数或产生错误的坐标因子。</p>
<p><span class="briefing-item__label">具体动作：</span>对依赖 trTensor 或 BLS 输入的笔记本加入 hp/hm 频域化和 f(r) 因子的最小回归测试；输出表达式统一检查为 r[]，并显式核对 λ2 归一化。</p>
<p class="briefing-sources"><span>来源：</span><a href="https://github.com/BlackHolePerturbationToolkit/PerturbationEquations/commit/e2e43a68600ecf1b1b760cd3d0f1213746c809ff">PerturbationEquations 官方修复提交</a></p>
</section>

<section class="briefing-item">
<h2>3. PyCBC／可复现环境：PyCBC 延后 Pixi 安装以避免未锁定 Python 3.15 的二进制依赖失败</h2>
<p><span class="briefing-item__label">核心内容：</span>PyCBC 的官方 CI 将 setup-pixi 的 run-install 设为 false，先由测试矩阵注入指定 Python 版本再求解环境。提交说明未锁定时会优先选择 conda-forge 的 Python 3.15，而 lalsuite 等二进制依赖尚无对应 wheel，导致安装失败。</p>
<p><span class="briefing-item__label">为什么相关：</span>这不是波形模型改动，但直接影响 PyCBC/LALSuite 开发环境能否被稳定复现，尤其是自动测试和从源码安装路径。</p>
<p><span class="briefing-item__label">具体动作：</span>本地 Pixi 或 CI 配置先锁定 Python 版本再安装依赖；对现有环境记录解释器与 LALSuite 构建来源，不把一次新解释器求解成功视为跨平台可复现。</p>
<p class="briefing-sources"><span>来源：</span><a href="https://github.com/gwastro/pycbc/commit/4dcfdf56837c">PyCBC 官方 CI 修复</a></p>
</section>

<section class="briefing-item">
<h2>4. LALSuite／发布元数据：LALSuite 完成面向打包元数据的 LVK Algorithm Library Suite 更名</h2>
<p><span class="briefing-item__label">核心内容：</span>LALSuite 官方提交将 conda 包的说明和 pkg-config 描述中的 LSC Algorithm 名称更新为 LVK Algorithm，并覆盖 lalburst、lalinference、lalinspiral、lalpulsar 与 lalsimulation 等组件。提交内容是名称与包元数据调整，没有改变库名、Python 导入名或波形实现。</p>
<p><span class="briefing-item__label">为什么相关：</span>发布自动化、依赖镜像和文档抓取若按旧描述过滤，可能出现发现或展示不一致；科学计算接口本身不应因此被重命名。</p>
<p><span class="briefing-item__label">具体动作：</span>更新内部包索引、镜像说明和文本匹配规则；保持现有 import、可执行文件与 ABI 检查不变，并在下次环境更新时验证实际包名。</p>
<p class="briefing-sources"><span>来源：</span><a href="https://git.ligo.org/lscsoft/lalsuite/-/commit/ff850e8b19358c12691337af2860ee5d6c6f9fb3">LALSuite 官方更名提交</a></p>
</section>

<h2>5. LALSuite／测试运行时：LALSuite 通用 CI 测试镜像迁至 Conda Python 3.14</h2>
<p><span class="briefing-item__label">核心内容：</span>LALSuite 的官方通用 CI 任务把默认 Conda 开发镜像从 Python 3.12 切换到 Python 3.14。该改动用于持续验证库及其 Python 绑定在新的解释器运行时下的构建和测试路径，而不是宣布用户环境必须立即升级。</p>
<p><span class="briefing-item__label">为什么相关：</span>对依赖 LALSuite 的 Python 工具链而言，这是上游兼容性覆盖范围扩展的直接信号，可帮助安排解释器升级验证。</p>
<p><span class="briefing-item__label">具体动作：</span>将 Python 3.14 作为额外矩阵环境运行最小波形生成、读写和导入 smoke test；在自身依赖均有可用二进制包前，保留已验证的生产解释器。</p>
<p class="briefing-sources"><span>来源：</span><a href="https://git.ligo.org/lscsoft/lalsuite/-/commit/554a92c6588e9db0e996f0fa457a6e9c0f58650d">LALSuite 官方 Python 3.14 CI 提交</a></p>

<section class="briefing-item">
<h2>6. LALSuite／Conda 可靠性：LALSuite 为 Conda 网络重试和最新发行版安装加入受限恢复路径</h2>
<p><span class="briefing-item__label">核心内容：</span>LALSuite 的官方开发 Conda 镜像设置了远端重试、退避和连接/读取超时，并把“安装最新 LALSuite 发行版”的步骤限制在 180 秒内。若该安装失败，现有 CI 会标记无可用发行版而继续执行适当的测试分支，避免无限等待。</p>
<p><span class="briefing-item__label">为什么相关：</span>依赖解析和网络超时会让科研软件的 CI 产生与物理无关的失败；该变更使发布验证更可诊断，也更利于复现失败条件。</p>
<p><span class="briefing-item__label">具体动作：</span>在自己的 CI 中区分依赖获取失败与数值测试失败，并保存解析日志；为联网安装设置明确上限，而不把超时后的部分环境用于科学结果比较。</p>
<p class="briefing-sources"><span>来源：</span><a href="https://git.ligo.org/lscsoft/lalsuite/-/commit/e4845fdc751adb6059947f82ee97916ae954d1b8">LALSuite 官方 Conda 可靠性提交</a></p>
</section>
