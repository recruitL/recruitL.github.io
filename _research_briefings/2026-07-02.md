## 1. Kerr 稳定性：全 subextremal Kerr 非线性稳定性证明

**来源/日期**：[arXiv:2606.28253](https://arxiv.org/abs/2606.28253)，提交 2026-06-26。

**一句话**：Peter Hintz 宣称解决了 full subextremal Kerr family 的全局非线性稳定性问题：接近 Kerr 的真空初值会衰减到另一个 Kerr 解，并给出空间紧区域内约 $\mathcal O(t_*^{-2-\epsilon_{\mathcal K}})$ 的趋近率；证明中不主要依赖标量化约化，除线性模稳定性中使用 Teukolsky 结构外，直接处理张量方程。

**为什么相关**：这是 Kerr 背景扰动理论的“地基级”结果。你做 Teukolsky/BHPT/QNM 时通常默认 Kerr 作为稳定背景；这篇给出更强的数学支撑，也提醒 gauge source、tail、最终 Kerr 参数都要作为非线性迭代中的未知量处理。

**建议动作**：不建议直接读 333 页全文；先读 abstract、introduction 和 proof strategy，重点摘出它如何使用 Teukolsky 线性模稳定性，以及它对尾项/gauge source 的处理。

## 2. 标量化：黑洞双曲散射中的 dynamical scalarization / descalarization

**来源/日期**：[arXiv:2606.30865](https://arxiv.org/abs/2606.30865)，提交 2026-06-29。

**一句话**：Pardoe 与 Witek 用数值相对论研究 quadratic scalar Gauss-Bonnet gravity 中黑洞双曲遭遇产生的标量场演化，在 decoupling limit 下发现本来不能保持标量发的构型可在 encounter 中短暂 scalarize；某些情况下黑洞自旋变化还能导致永久的 spin-induced scalarization 或 descalarization。

**为什么相关**：这和你最近关心的“标量云/标量发/背景反作用”在物理机制上相邻，但它强调的是 **动态 encounter** 而不是静态束缚云。对 PM/scattering 与 modified gravity 标量响应的连接很有价值。

**建议动作**：先看 scalar field equation、decoupling approximation 和初始标量种子的设定；把它放到 `scalarization / scattering / modified gravity` 标签下，不要和静态 scalar cloud 本征值问题混为一谈。

## 3. 暗物质 halo 背景：Hernquist halo 中的旋转黑洞

**来源/日期**：[arXiv:2606.30962](https://arxiv.org/abs/2606.30962)，提交 2026-06-29。

**一句话**：Araújo Filho 等从 Hernquist 分布的静态 halo 黑洞出发，用 noncomplexification Newman–Janis 算法构造旋转对应物，并分析 halo 参数对视界、ergoregion、ZAMO 角速度、温度、熵和 Hawking 辐射的影响；弱 halo/慢转动极限下恢复 Kerr/Schwarzschild。

**为什么相关**：它和你当前的“Schwarzschild/rotating BH + dark matter halo + scalar perturbation”背景构造问题相关，尤其是如何从静态 halo metric 生成旋转 metric 的做法。但 Newman–Janis 类旋转化在物理一致性上常需要额外检查。

**建议动作**：只抽取 metric、$\Delta(r)$、horizon condition 和 Kerr/Schwarzschild 极限；如果要用于 Teukolsky/SN 或 KG 分离，必须先检查可分性、Petrov type、Ricci tensor 和源项一致性。

## 4. ECO / compactness：PhenomDECO 对 GWTC-3 做 compactness 鲁棒性测试

**来源/日期**：[arXiv:2606.31350](https://arxiv.org/abs/2606.31350)，提交 2026-06-30；伴随 population 版本 [arXiv:2606.31364](https://arxiv.org/abs/2606.31364)。

**一句话**：Ghosh、Hoy、Hannam、Ohme 用带 effective compactness 参数的 PhenomDECO 检验 GWTC-3 高显著 BBH 事件是否偏离黑洞 merger morphology；低 compactness 模式在提高起始频率后会消失，说明低频噪声处理会直接影响“疑似 ECO”结论。伴随文章进一步把 compactness 作为 population observable，得到 $C_{\rm eff}=0.5^{+0.3}_{-0.1}$ 并限制低 compactness exotic binary merger rate。

**为什么相关**：这和 ringdown/ECO/modified compact object 检验有关，也给出一个很现实的警告：所谓非黑洞证据可能来自低频 glitch 或数据处理，而不是新物理。

**建议动作**：重点看他们如何定义 effective compactness、如何处理 Livingston 低频数据、如何用 time-frequency residual 做 robustness diagnostic；这比直接看 posterior 图更重要。
