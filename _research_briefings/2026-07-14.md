## 1. 标量场 EMRI：首个含 1PA 自力的 beyond-GR 波形模型

**来源/日期**：[arXiv:2607.09310](https://arxiv.org/abs/2607.09310)，2026-07-10。

**一句话**：Barsanti、Burke、Maselli、Sotiriou、Spiers、Warburton 构建了首个同时包含 **一阶 post-adiabatic 引力动力学**和额外标量辐射的自力波形模型，用于 LISA 中 IMRI/EMRI 的标量荷测量。忽略引力部分的 1PA 会偏置质量等本征参数，但在其测试范围内，标量荷约束相对稳健。

**为什么重要**：这与你当前的标量扰动、GSF 和 LISA 退相位主线几乎完全重合。尤其值得注意的是，作者发现准圆、非旋主黑洞情况下，leading dipole PN scalar flux 相对全相对论标量流量产生的系统误差很小。

**具体动作**：优先拆解其阶数结构：
\[
\text{1PA GR sector}+\text{leading scalar sector},
\]
确认标量荷、自旋和质量比如何计阶；再与你当前的 \((1,1)\)、\((1,2)\) 标量—度规展开逐项对应。

## 2. EMRI 环境效应：偏心率可帮助区分暗物质与吸积盘

**来源/日期**：[arXiv:2607.09214](https://arxiv.org/abs/2607.09214)，2026-07-10。

**一句话**：文章比较 NFW/Beta 暗物质 halo 与薄 \(\alpha\)-disk 对偏心 EMRI 的相位修正，发现暗物质退相位对初始偏心率 \(e_0\) 较不敏感，而吸积盘效应会随 \(e_0\) 增大而明显减弱。

**为什么重要**：这给出了比单纯比较总退相位更有效的环境判别变量：不仅看 \(\Delta\Phi\)，还看其对 \(e_0\) 的响应。它与你计划研究的 scalar-cloud profile dependent dephasing 也有直接类比。

**具体动作**：在环境波形代码中预留
\[
\partial\Delta\Phi/\partial e_0
\]
这一诊断量。以后比较 Hernquist、NFW、标量云和盘模型时，同时画 \(\Delta\Phi(e_0)\)，而不是只给圆轨道结果。

## 3. LISA/TianQin：几何 TDI 中的时钟噪声扣除

**来源/日期**：[arXiv:2607.09335](https://arxiv.org/abs/2607.09335)，2026-07-10。

**一句话**：Luo 等在 geometric TDI 框架内构造统一的 clock-noise subtraction，把时钟噪声残差写成与激光噪声残差平行的代数结构，并覆盖同时包含 delay 与 time-advance operator 的任意双路径 TDI 组合。

**为什么重要**：即使激光相位噪声已由 TDI 抵消，星载超稳振荡器的 clock jitter 仍可能高于次级噪声并影响 Fisher/MCMC 参数约束。对高精度 LISA EMRI 或 modified-gravity 推断，这属于不能继续忽略的 detector systematic。

**具体动作**：在你的 LISA pipeline 检查表中加入：

`orbit model → link response → TDI generation → clock calibration → PSD/covariance → likelihood`

不要把 clock noise 简单并入固定 PSD，而应检查其扣除前后的通道互相关。

## 4. Ringdown/进动推断：波形模型与 glitch 模型存在耦合

**来源/日期**：[arXiv:2607.09111](https://arxiv.org/abs/2607.09111)，2026-07-10。

**一句话**：新工具 `bilby_glitch` 可同时对 GW 信号与非高斯 glitch 做 Bayesian inference；重新分析 GW200129 时，是否支持强自旋进动会同时依赖所用波形模型和 glitch 参数化。

**为什么重要**：这对近期 direct-wave、ringdown、higher-mode 和 catalog-level GR tests 是明确警告：数据清理和波形建模不是两个可完全分离的步骤。某个“额外模”或“进动证据”可能由二者的耦合产生。

**具体动作**：以后分析异常 ringdown 成分时至少交叉运行：

\[
\text{多套 waveform approximants}
\times
\text{多套 glitch models},
\]

并把模型间 posterior 漂移作为系统误差，而不是只报告单一 Bayes factor。

## 5. Kerr–Hernquist 标量云：直接相关，但应先做文献质量检查

**来源/日期**：[arXiv:2607.08796](https://arxiv.org/abs/2607.08796)，2026-07-08。

**一句话**：该预印本对 Newman–Janis 生成的 Kerr–Hernquist 背景研究准束缚态、同步标量云、黑洞炸弹和超辐射放大，声称 halo 增强束缚能但压低共转模超辐射增长率。

**为什么重要**：主题与你的“暗物质 halo + scalar cloud + rotating background”完全重合；但 arXiv 页面明确标有与 [arXiv:2606.10332](https://arxiv.org/abs/2606.10332) 存在文本重叠的管理员提示，因此不应直接作为核心理论依据。

**具体动作**：阅读前先完成三项核验：

1. 比较两篇文章的径向方程和 matched-asymptotic 推导；
2. 独立验证 Newman–Janis 度规的 Einstein tensor、物质源与可分离性；
3. 检查同步条件是否仍严格为 \(\omega=m\Omega_H\)，还是被 halo 的渐近时间归一化修改。

## 6. BHPT 更新：`h1Lorenz` 适合作为你当前 polar 推导的基准

**来源/日期**：Black Hole Perturbation Toolkit，仓库更新于 2026-07-13。

**一句话**：`h1Lorenz` 计算 Schwarzschild 圆轨道粒子产生的一阶 Lorenz-gauge 度规扰动及其径向导数，使用 Barack–Lousto–Sago 张量球谐基，并输出完整分量到 HDF5。

**为什么重要**：你当前正从 Einstein 分量方程约化 polar/axial 系统并考虑如何重建 \(h_0,h_1,H_0,H_1,H_2,K\)。该仓库可作为完全独立的数值/规范基准，而不仅是最终 flux 对比。

**具体动作**：选 \(r_0=8M\) 或 \(8.1M\)，先比较一个 \((\ell,m)=(2,2)\) 模的各分量与径向导数。注意 README 明确警告 even-\(\ell,m=0\) 模因齐次解积分区间过长而可能不准确，不能把这些模作为首批 benchmark。
