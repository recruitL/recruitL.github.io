## 1. EMRI / 次级自旋：通用 Kerr 轨道的通量和波形框架更新

**来源/日期**：[arXiv:2603.18075](https://arxiv.org/abs/2603.18075) v3，2026-07-14 修订。

**一句话**：Cui 与 Han 在次级天体自旋的一阶近似下，为 Kerr 中通用 EMRI 构造波形和轨道平均通量；采用半延迟减半超前的 radiative prescription，计算能量、角动量及 Carter-like 常数的演化。

**为什么重要**：次级自旋是从一阶绝热 EMRI 走向高精度模板时不可忽略的 \(\mathcal O(qs)\) 修正，也会和主黑洞自旋、倾角、偏心率及保守自力产生相关性。该工作尤其值得检查其 Carter-like 常数通量如何定义，以及是否与 MPD/osculating-elements 轨道变量严格匹配。

**具体动作**：按以下极限做独立验证：

\[
s_2\rightarrow0,\qquad e\rightarrow0,\qquad \iota\rightarrow0,
\]

并分别比较 \(\dot E,\dot L_z,\dot Q\) 与无自旋 Teukolsky 通量。随后检查线性自旋截断在近 separatrix 区域是否仍保持量级层次。

## 2. Modified BHPT / PM：高阶导数引力波形修正在 5PN 出现

**来源/日期**：[arXiv:2606.07070](https://arxiv.org/abs/2606.07070) v2，2026-07-15 修订。

**一句话**：Cano 等为含 Riemann 三次、四次收缩的高阶导数引力，推导带任意源的 odd/even-parity 主方程，并构造齐次解的 PM 展开；圆轨道波形及无穷远能量、角动量通量的修正从 5PN 开始，并与 \(\ell=2\) Love number 成正比。作者同时提供含主方程和 PM 解的 Mathematica notebook。

**为什么重要**：这与你当前从 Einstein 分量方程约化 axial/polar 主方程的工作高度一致，也给出一个明确接口：

\[
\text{modified master equation}
\rightarrow
\text{PM homogeneous solution}
\rightarrow
\text{PN waveform/flux}
\rightarrow
\text{Love number}.
\]

它还说明高阶曲率效应在波形中的 leading correction 不一定表现为低 PN 阶的简单势函数偏移。

**具体动作**：优先下载 ancillary notebook，检查：

1. GR 极限是否恢复 RW/Zerilli；
2. arbitrary-source 项中是否包含 \(\delta'\)；
3. odd/even 扇区的边界归一化；
4. 5PN 修正是否能映射为 EOB 波形或辐射反作用中的单一 tidal/Love 系数。

## 3. LISA 数据分析：用动态功率谱处理非平稳噪声

**来源/日期**：[arXiv:2607.13168](https://arxiv.org/abs/2607.13168)，2026-07-14。

**一句话**：Cornish 提出以动态功率谱 \(S(f,t)\) 描述非平稳噪声，并通过 Gram-factor 构造保证噪声协方差正半定；框架可统一写在频域、时域及 Wilson–Daubechies wavelet 域中，示例包括窗函数效应和空间探测器中银河双星信号调制引起的非平稳性。

**为什么重要**：持续数月到数年的 EMRI 信号不能默认整个观测期共用一个固定 PSD。轨道调制、银河前景变化、数据缺口和仪器漂移可能把非平稳噪声误吸收到缓慢相位修正、环境效应或 modified-gravity 参数中。

**具体动作**：在现有 likelihood 外增加分块诊断：

\[
S(f)
\quad\longrightarrow\quad
S(f,t_k),
\]

分别比较固定 PSD、分段 PSD 和 wavelet covariance 下的 posterior。第一轮只需注入真空 EMRI，测试非平稳噪声是否会伪造标量荷或 halo 退相位。

## 4. Ringdown：cWB 重建可收紧 \(220\) 模约束，但更依赖早期拟合稳健性

**来源/日期**：[arXiv:2607.13275](https://arxiv.org/abs/2607.13275)，2026-07-14。

**一句话**：Kumar 等先用 coherent WaveBurst 重建信号，再进行 ringdown 分析；对 GWTC-3 事件的联合结果为

\[
\delta f_{220}=0.003^{+0.028}_{-0.028},\qquad
\delta\tau_{220}=0.050^{+0.081}_{-0.086},
\]

均与 GR 一致。精度提升主要来自降噪以及把分析窗口推进到更靠近并合的时刻。

**为什么重要**：更早开始拟合能够提高 SNR，但也更容易混入非线性 merger、overtones、mode mixing 和 direct/prompt component。因此“误差条更小”不自动等于“系统误差更小”。

**具体动作**：检查结果对以下设置的稳定性：

\[
t_{\rm start},\quad
N_{\rm overtone},\quad
\text{cWB reconstruction prior},\quad
\text{glitch model}.
\]

尤其应把原始 strain 与 cWB 重建后的 ringdown posterior 并列，而不是只看重建数据的联合约束。

## 5. LISA Global Fit：群体推断必须同时使用已解析源与未解析背景

**来源/日期**：[arXiv:2601.04168](https://arxiv.org/abs/2601.04168) v5，2026-07-15 修订，已匹配 JCAP 发表版本。

**一句话**：Toubiana 与 Gair 建立从 LISA Global Fit 输出直接进行层级贝叶斯群体推断的框架，同时纳入 individually resolved sources 和 unresolved stochastic background，并展示“已解析源”的 SNR 阈值会影响最终群体结论。

**为什么重要**：EMRI、银河双星和大质量黑洞双星并非彼此独立地从数据中提取。阈值以下的源不会简单消失，而会进入混淆背景；若只对 catalog 做 selection correction，可能遗漏背景所携带的群体信息。

**具体动作**：今后设计 LISA EMRI population/MG 流程时，将分析层级写为：

```text
raw TDI data
→ joint Global Fit
→ resolved-source posteriors + unresolved component
→ hierarchical population inference
```

不要直接套用地面探测器常见的“事件 catalog + detection efficiency”结构。

## 6. LISA / Taiji 偏振检验：用 null-response channel 隔离 breathing 模

**来源/日期**：[arXiv:2607.13483](https://arxiv.org/abs/2607.13483)，2026-07-15。

**一句话**：Xu、Tang 与 Wu 针对额外横向标量 breathing polarization，利用动态三角星座模型构造 null-response channel，以压制其他偏振贡献，并计算 Taiji/LISA 类通道的响应和灵敏度。

**为什么重要**：其具体 GQFT 理论动机需要独立评估，但 null-channel 方法本身可用于更一般的标量—张量或额外偏振检验。与直接在标准 Michelson 通道中同时拟合多个偏振相比，null channel 更接近探测器层面的模型无关诊断。

**具体动作**：只优先复现 detector response 部分，检查：

- NRC 是否在有限臂长和轨道运动下仍真正抑制 tensor modes；
- 时钟噪声和 TDI 残差是否会泄漏进 null channel；
- breathing mode 与天区位置、倾角之间是否仍存在强简并。

暂不把文章中的特定引力理论作为主线。
