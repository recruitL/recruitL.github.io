## 1. Ringdown / ECO：一种“没有 ringdown 的 relaxation”模型

**来源/日期**：[arXiv:2607.00559](https://arxiv.org/abs/2607.00559)，提交 2026-07-01。

**一句话**：Tasinato 构造一个外部为 Schwarzschild、内部由 vector–tensor 理论支撑的紧致物体；其 odd-parity 响应不是通常的振荡 QNM，而是纯耗散 relaxation poles，黑洞极限通过 relaxation modes 消失来逼近，而不是通过出现 ringdown 来逼近。

**为什么相关**：这对你关心的 **ringdown、ECO、Green function、effective membrane response** 有直接参考意义；它提醒“黑洞状外部 + 正则内部”未必对应传统 QNM 图像。

**建议动作**：优先看 odd-parity sector、retarded Green function 和 susceptibility 的解析结构；不要先看完整 vector–tensor 模型细节。

## 2. LISA / modified gravity：环境效应与 $\dot G$ 在单事件层面简并

**来源/日期**：[arXiv:2607.00845](https://arxiv.org/abs/2607.00845)，提交 2026-07-01。

**一句话**：Copparoni 与 Barausse 比较 LISA massive black-hole binaries 中 circumbinary disk 的 accretion/viscous migration 与 time-varying Newton constant $\dot G$；三者在 leading order 都进入相同的负 PN 阶相位形变，因此单事件层面形式上简并，但 population-level 分析显示现实环境效应不太会系统性污染 LISA 对 GR 的检验。

**为什么相关**：这正是 **source environment vs modified gravity** 的判别问题。你以后写 LISA/TianQin 检验 modified gravity 或暗物质环境效应时，这篇可以作为“单事件简并、群体统计破简并”的清晰例子。

**建议动作**：摘出它的共同 phase-deformation parameter、负 PN 阶数、Fisher + hierarchical nested sampling 设定，放进 `LISA_environment_vs_MG` 标签。

## 3. 暗物质 halo / EMRI：Dehnen-type halo 对周期轨道和 mHz 波形的影响

**来源/日期**：[arXiv:2607.00812](https://arxiv.org/abs/2607.00812)，提交 2026-07-01。

**一句话**：Shokirov 等研究 Schwarzschild-like 黑洞嵌入 generalized Dehnen-type $(1,4,\gamma)$ dark-matter halo 后的 timelike geodesics、periodic orbits 和 numerical-kludge GW；增大 halo 参数会推大 MBO/ISCO 半径、延长周期轨道、降低波形振幅，频谱主要落在 LISA/Taiji/TianQin 的 mHz 区间。

**为什么相关**：这与你近期做的 **黑洞 + halo + 标量场/EMRI** 问题高度相关，但它仍是 kludge 层级，不是自洽 GSF/Teukolsky 波形。

**建议动作**：只抽取 metric、effective potential、ISCO/MBO shift 和周期轨道分类；不要把 numerical-kludge 相位差当作 LISA 精度结论。

## 4. LVK / ringdown：GW230814 的 $\ell=|m|=4$ 模与 ringdown 小偏差

**来源/日期**：[arXiv:2509.07348](https://arxiv.org/abs/2509.07348) v2，2026-06-30 修订；ApJL 1004, L23。

**一句话**：LVK 报告 GW230814 是 GWTC-4.0 中 Livingston 单探测器观测到的高 SNR 事件，SNR 为 42.4；其高信噪比使 $\ell=|m|=4$ inspiral-merger-ringdown 模首次被识别，同时 ringdown phase 有轻微偏离迹象，但含 GR 与真实噪声的模拟也能复现类似偏离，因此不能作为 GR 失效证据。

**为什么相关**：这对 **higher modes、single-detector inference、ringdown consistency tests** 都很有用，也能作为“高 SNR 不等于强理论检验”的案例。

**建议动作**：重点看 ringdown consistency test 和 detector-noise injection 部分；把它和前几天的 GW250114/direct-wave 讨论分开，避免混用结论。

## 5. 标量发 / scalar hair：resonant-hair 黑洞的非球对称不稳定性

**来源/日期**：[arXiv:2604.22437](https://arxiv.org/abs/2604.22437) v2，2026-06-30 修订。

**一句话**：Ferreira、Herdeiro、Radu、Zilhão 进一步研究 Einstein–Maxwell–(gauged-)scalar 系统中 resonant-hair 黑洞，给出非球对称动力学下的两个衰变通道：分裂成 bosonic lump + bald black hole，或直接塌缩/吸收到 bald black hole；作者认为这种不稳定性可能对不同 self-interaction 类别具有普遍性。

**为什么相关**：这和你当前的 **标量云、标量发、反作用稳定性** 线相邻。它提醒：球对称下看似稳定的 scalarized/hairy solution，放开非球对称扰动后可能完全不稳。

**建议动作**：只读模型、非球对称扰动设置和 decay-channel 诊断；对你的标量云工作，重点借鉴“稳定性不能只看径向模”的警告。
