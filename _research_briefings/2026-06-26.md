## 1. Ringdown：direct wave 作为 horizon probe 的限制

**来源/日期**：[arXiv:2606.25021](https://arxiv.org/abs/2606.25021)，2026-06-23。

**一句话**：Dyer、Chung、Moore 从数值相对论 ringdown 波形中抽取 prompt/direct waves，并测试“horizon-mode model”；结果显示 direct wave 频率可被稳定识别，但偏离 horizon 预期值，因此作为事件视界几何探针的能力受限。

**为什么相关**：这正好落在 QNM/ringdown、非模态成分、horizon response 的交界处；如果你在做 VAM/TTM、EP 或 QNM 展开有效性，这篇值得细读。

**建议动作**：先看其 supplemental 中 direct-wave extraction 的 fit window 和 start-time dependence，和你已有 ringdown fitting 流程对照。

## 2. GSF/BHPT：Bondi–Sachs gauge、BMS frame 与 memory 进入二阶自力波形

**来源/日期**：[arXiv:2606.24816](https://arxiv.org/abs/2606.24816)，2026-06-23。

**一句话**：Spiers、Pound、Moxon 提出在 Kerr 背景上迭代变换到 Bondi–Sachs gauge 并固定 BMS frame 的框架，目标是处理 GSF 波形中的 far-zone gauge singularities、IR divergences 和 memory effects。

**为什么相关**：这是二阶 GSF/EMRI waveform 的“规范控制”问题，不是技术边角料；LISA 精度下，BMS frame 和 memory 不能只在后处理中补丁式加入。

**建议动作**：优先读摘要后半和 formalism 部分，标记其中对 multiscale expansion 与 “forgetful gauges” 的定义，后续可和 post-adiabatic EMRI pipeline 对接。

## 3. QNM 展开：Schwarzschild Green function 的收敛区域有新的 radial-scattering 解释

**来源/日期**：[arXiv:2606.24812](https://arxiv.org/abs/2606.24812)，2026-06-23。

**一句话**：Kehagias 与 Riotto 从 radial mirror scattering 角度重访 Schwarzschild retarded Green function 的 QNM 展开收敛区域，把 direct 与 mirror contributions 解释为半线问题中的两个传播通道。

**为什么相关**：对 QNM expansion “什么时候能用”给出更几何化的诊断；与你关心的 QNM 收敛、branch cut/direct wave、ringdown 建模区间选择直接相关。

**建议动作**：把文中的 convergence condition 和你现有的 Leaver/Green-function 数值结果做一个小表，对比 tortoise-coordinate 反射点的作用。

## 4. PM/EOB/NR：generic-spin 黑洞散射首次用 NR 对高阶 PM 预测做强场检验

**来源/日期**：[arXiv:2606.24432](https://arxiv.org/abs/2606.24432)，2026-06-23。

**一句话**：Clark、Pratten、Schmidt 比较 generic-spin 黑洞散射的高阶 PM 预测与 NR，发现 NR 中出现强场 precessional turning-point structure，包括 PM 结果中缺失的 polar-angle sign change。

**为什么相关**：这对 eccentric/precessing waveform、EOB scattering-angle calibration、PM/GSF 互补非常有价值，尤其适合用作 EOB 非圆轨道强场校准约束。

**建议动作**：重点看他们如何定义 asymptotic Euler angles 和 azimuthal/polar scattering angles；可考虑加入你的 EOB/PM 文献追踪列表。

## 5. Spinning test particle：线性自旋阶 Hamilton–Jacobi 可分性的充分条件

**来源/日期**：[arXiv:2606.25792](https://arxiv.org/abs/2606.25792)，2026-06-24。

**一句话**：Witzany 与 Skoupý 构造 worldline-adapted tetrad 中的 spinning test particle Hamiltonian，并证明若 geodesic motion 与沿 geodesic 的 parallel transport 都可分，则线性自旋阶 Hamilton–Jacobi 方程也可分；还附带 `SpinSepExamples.nb`。

**为什么相关**：这对 spinning secondary 的 EMRI/GSF 轨道动力学、action-angle 变量、可分结构非常实用。

**建议动作**：下载 ancillary Mathematica notebook，检查 Kerr 情况下的变量选择是否能直接复用于你现有的轨道/Teukolsky 计算笔记本。

## 6. Modified gravity：DHOST 黑洞径向扰动的稳定性与“非 tortoise”径向坐标

**来源/日期**：[arXiv:2606.25972](https://arxiv.org/abs/2606.25972)，2026-06-24。

**一句话**：Charmousis、Iteanu、Langlois、Noui 研究 DHOST 理论中带 primary hair 的静态黑洞径向扰动，把 monopole 模重写为平直径向波方程，并讨论正自伴算符、stealth 解与稳定传播自由度。

**为什么相关**：虽然不是 Kerr ringdown，但它提供了 modified gravity 黑洞扰动中边界条件、稳定性和径向坐标选择的清晰案例，可作为 MG-QNM 检验的理论参照。

**建议动作**：只需先扫读第 2–4 节，关注边界条件和 self-adjoint extension；暂不必深挖具体 DHOST 参数空间。
