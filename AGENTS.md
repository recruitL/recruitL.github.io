# Repository Instructions

- When modifying frontend UI, first use the frontend-design skill. Do not implement immediately; propose the design direction and file-level plan first.
- When updating conference or activity records, only add meetings the user explicitly asks to add or explicitly says they attended. Do not infer or add adjacent meetings from screenshots, forwarded notices, surrounding text, or prior/next-year references.
- Conference/activity page entries must use the concise format: conference name, linked only when the user supplied the official meeting URL, plus address in province-city form such as `省份·城市`. Do not add unrequested venue details, organizers, attendance counts, schedules, weather, contacts, or summary prose.
- If the user does not provide a meeting URL, leave the title unlinked and do not search for or invent one unless the user explicitly asks. Internal map coordinates may use the provided city only, but must not become venue-level claims.
